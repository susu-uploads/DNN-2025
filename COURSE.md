### **Аннотация учебного курса**

Искусственные нейронные сети являются одним из самых важных и быстро развивающихся направлений в области современных информационных технологий. Сегодня системы искусственного интеллекта на базе нейронных сетей успешно решают сложные задачи в самых различных областях: управляют беспилотными автомобилями и геликоптерами, выявляют патологии на рентгеновских снимках, оцифровывают рукописный текст, распознают лица людей с камер видео-наблюдения, осуществляют биржевые операции с ценными бумагами и решают много других задач, делая это лучше, чем человек. Цель настоящего курса – дать студентам теоретические знания и практические навыки по использованию технологий нейронных сетей для решения практических задач, связанных с применением методов искусственного интеллекта. В ходе обучения студенты знакомятся с типовыми архитектурами искусственных нейронных сетей, методами их обучения и проверки. На практических занятиях студенты применяют полученные знания к созданию на языке Python искусственной нейронной сети, распознающей рукописные цифры.

##### **Оценивание**

Для оценивания результатов обучения студента применяется [балльно-рейтинговая система](https://nte.susu.ru/wordpress/wp-content/uploads/2019/06/Polozhenie.pdf). Оценка за дисциплину выставляется студенту на основе его итогового рейтинг \(R_{д}=max(R_{тек},R_{экз+})\), где \(R_{тек}\) - рейтинг обучающегося по результатам текущего контроля без учета экзамена, \(R_{экз+}\) - рейтинг обучающегося с учетом результатов экзамена. Рейтинг обучающегося по результатам текущего контроля вычисляется по формуле \(R_{тек}=0.6 \times R_{пт}+0.4 \times R_{пр}+B_{оп}\), где \(R_{пт}\) - рейтинг обучающегося по результатам выполнения промежуточных тестов, \(R_{пр}\) - рейтинг обучающегося по результатам выполнения практических работ, \(B_{оп}\) - бонусные баллы за очное посещение лекций (за каждое очное посещение лекции начисляется один балл). Рейтинг обучающегося с учетом результатов экзамена вычисляется по формуле \(R_{экз+}=0.6 \times R_{тек}+0.4 \times R_{ит}+B_{оп}\), где \(R_{ит}\) - процент правильных ответов на вопросы итогового теста. Максимальное значение рейтинга любого вида равно 100.

Студент с рейтингом по текущему контролю \(R_{тек} \geq 60\) имеет право отказаться от прохождения итогового теста. В этом случае он должен поставить соответствующую отметку в личном кабинете системы "Универис" в течение суток, предшествующих проведению экзамена (при этом приходить на экзамен не требуется). Студент с \(R_{тек} \geq 60\) может отказаться от прохождения итогового теста на экзамене лично. Если студент не поставил отметку в системе "Универис", не пришел на экзамен и его \(R_{тек} < 85\), то в экзаменационной ведомости вместо оценки будет поставлена "неявка" и студент становится задолжником. Студенту с \(R_{тек} \geq 85\) в любом случае выставляется оценка "отлично".

|  |  |
| --- | --- |
| **Шкала перевода баллов в оценку** | |
| **Кол-во баллов** | **Оценка** |
| 85-100 | "отлично" |
| 75-84 | "хорошо" |
| 60-74 | "удовлетворительно" |
| 0-59 | "неудовлетворительно" |
